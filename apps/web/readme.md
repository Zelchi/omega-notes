# Site de divulgação

Pasta reservada ao site público do Ômega Notes.

- `src/`: código do site.
- `public/`: imagens e arquivos públicos do site.

A página, o framework e a hospedagem serão definidos na implementação do site.
O aplicativo desktop fica em `../desktop` e possui build e dependências próprios.
Não coloque chaves ou arquivos privados do aplicativo nesta pasta.
